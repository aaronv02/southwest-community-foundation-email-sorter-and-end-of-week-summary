Inbox Steward

    Press Sort my inbox and everything new gets a colored label. Anything it isn't sure about is labelled Needs Review rather than guessed at.

    Once Inbox Steward has seen you file a sender a few times, it teaches that to Outlook directly. Those senders are then sorted the moment mail arrives — even when this panel is closed.

    Rename anything, or edit a description to change what lands there. The description is what the sorter actually reads, so being specific pays off.
